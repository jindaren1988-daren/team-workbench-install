# 团队工作台

在 DeepSeek Harness 进入项目、任务、成果空间及成员收件箱。项目管理员通过项目卡片邀请成员。授权的成员可以提交成果，指定验收人决定版本是否通过。

空间默认显示最近通过的交付版本。网页构建从项目资料上传静态输出目录，随成果版本提交，在隔离预览中操作。项目范围的模型工具由「Agent 与报告」签发的专用连接启用。

## 个人设置

安装完成并通过邀请码登录后，点工作台右上角「个人设置」，修改自己的显示名或选择、替换、移除头像，保存后同步给团队。设置不属于安装或首次登录的必填步骤。项目和角色权限仍跟随原成员ID。照片支持PNG、JPEG、WebP，最多2MiB，宽高不超过4096；服务端重编码保存。
